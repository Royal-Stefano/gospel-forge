# Hostinger Cloud Startup Deployment Guide — Gospel Forge

This guide details the deployment of **Gospel Forge — The Forged Frequency** on Hostinger Cloud Startup using the native Node.js Application Manager.

---

## 1. Prerequisites on Hostinger

1. Log into your **Hostinger hPanel**.
2. Navigate to **Websites** -> Select your domain (e.g., `gospelforge.com`).
3. Under the **Advanced** section, click **Node.js**.

---

## 2. Node.js Environment Setup

In the Hostinger Node.js configuration panel:
- **Node.js Version**: Select **Node.js v20+** or **Node.js v22+** (Hostinger Cloud supports modern LTS versions).
- **Application Root**: `public_html` or the root folder of your project.
- **Application Startup File**: `server.js` (generated by Next.js standalone build) or `node_modules/next/dist/bin/next` with argument `start`.
- **Application Mode**: `Production`.

---

## 3. Environment Variables

Add the following environment variables in the Hostinger Node.js manager or via `.env.production`:

| Variable | Description |
| :--- | :--- |
| `NODE_ENV` | `production` |
| `PORT` | `3000` (or the port assigned by Hostinger) |
| `NEXT_PUBLIC_APP_URL` | `https://gospelforge.com` |
| `NEXT_PUBLIC_SUPABASE_URL` | Your Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Your Supabase client anonymous key |
| `SUPABASE_SERVICE_ROLE_KEY` | Your Supabase service role key (backend only) |
| `PODCAST_RSS_URL` | Your primary podcast RSS feed URL |
| `CRON_SECRET` | Secret token shared with GitHub Actions |

---

## 4. Build and Deployment Process

### Option A: Direct Git Deployment (Recommended)
1. Push code to your private GitHub repository.
2. In Hostinger Git section, add the repository webhook.
3. In the SSH / Web Terminal, run:
```bash
npm ci
npm run build
```
4. Copy the standalone files:
```bash
cp -r .next/standalone/* ./
cp -r .next/static ./.next/standalone/.next/
cp -r public ./.next/standalone/
```
5. Click **Restart** in the Node.js panel.

### Option B: Local Build & FTP / SSH Upload
1. Run `npm run build` locally.
2. Upload `.next/standalone`, `.next/static`, and `public` to your Hostinger server directory.
3. Start the application with `node server.js`.

---

## 5. Domain & SSL Verification

1. In Hostinger hPanel, go to **SSL**.
2. Ensure **Let's Encrypt SSL** is active and set to **Force HTTPS**.
3. Verify that HTTP traffic automatically redirects to `https://gospelforge.com`.

---

## 6. GitHub Actions Automated RSS Synchronization

1. In your GitHub repository, go to **Settings** -> **Secrets and variables** -> **Actions**.
2. Add secrets:
   - `GOSPEL_FORGE_URL`: `https://gospelforge.com`
   - `CRON_SECRET`: Your configured `CRON_SECRET`
3. The workflow in `.github/workflows/rss-sync.yml` runs every 15 minutes to ingest new podcast episodes.

---

## 7. Rollback Instructions

If an update requires immediate rollback:
1. In Hostinger Git / File Manager, checkout the previous stable tag or commit:
```bash
git checkout <previous-commit-hash>
npm run build
```
2. Restart the Node.js application in hPanel.
